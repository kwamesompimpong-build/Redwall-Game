# Redwall: The Warrior's Quest

A browser-based top-down action RPG inspired by Brian Jacques' beloved Redwall book series.

## Play

Open `index.html` in any modern web browser. No build tools or servers required.

## Story

You play as **Matthias**, a young mouse of Redwall Abbey. When **Cluny the Scourge** and his vermin horde threaten to destroy the peaceful Abbey, you must find the legendary **Sword of Martin the Warrior** and rally the woodland creatures to defend your home.

## Controls

| Key | Action |
|-----|--------|
| WASD / Arrow Keys | Move |
| SPACE | Interact / Advance dialogue |
| I | Open inventory |
| Q | Open quest journal |
| ESC | Pause menu |
| A / D / S / F | Combat: Attack / Defend / Special / Flee |

## Features

- **10 explorable maps**: Redwall Abbey (grounds, Great Hall, Cavern Hole, cellars, belltower, tunnels), Mossflower Woods (south, deep), the Old Quarry, River Moss, and Cluny's War Camp
- **Turn-based combat** with Attack, Defend, Special moves, and Flee
- **Quest system** tracking the main storyline and side quests
- **Inventory system** with weapons, shields, consumables, and quest items
- **Iconic characters**: Matthias, Abbot Mortimer, Constance the Badger, Cornflower, Brother Methuselah, Warbeak Sparrow, Skipper of Otters, Log-a-Log, Cluny the Scourge, and more
- **Pixel art sprites** rendered via Canvas 2D
- **Procedural chiptune music** and sound effects via Web Audio API
- **Save/load system** using localStorage
- **Boss battle** against Cluny the Scourge

## Based On

*Redwall* by Brian Jacques (1986). This is a fan-made tribute game.
